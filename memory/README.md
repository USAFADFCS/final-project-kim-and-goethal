# Project memory

Durable architectural context for the CTF Solver.  Per [`CLAUDE.md`](../CLAUDE.md):

- This directory holds reference docs: architectural decisions, design
  rationale, capability inventories, and the "why" behind non-obvious
  choices.
- These are **not** task trackers.  Task status lives in `# TODO:` comments
  inside the relevant `.py` files.
- Update or remove entries that become outdated; don't let stale decisions
  drift.

Not to be confused with Claude Code's auto-memory under
`~/.claude/projects/<slug>/memory/`, which is ephemeral per-session state.
The files here are committed to source.
